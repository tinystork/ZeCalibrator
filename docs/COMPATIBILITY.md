# Compatibility

Supported Python: CPython 3.13.x

Python 3.11: unsupported due to reproducible native instability in the
Qt-worker/Astropy workload.
Python 3.12: not currently qualified.
Python 3.14+: not currently qualified.

Observed: reproducible native instability under CPython 3.11 in this workload;
not reproduced under CPython 3.13 in the bounded investigation.
